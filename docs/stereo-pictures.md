# Native stereo picture boundary

A decoded `Frame` keeps immutable native samples, presentation index and time, exact sample aspect and the MP4 st3d mark of that presentation sample's selected description.
`stereo::view` interprets one complete spatial picture through craft-media's sample-grid copier, retaining the single presentation identity and each eye's source grid.
The API keeps source metadata separate from an explicit caller override and eye swap.
No window, desktop protocol, player clock or output-mode choice is introduced by this topic.

Automatic MP4 st3d works for Motion JPEG and ProRes.
Automatic H.264 is explicitly refused until the shared decoder exposes codec stereo marks, so a container mark cannot silently win over an unexamined SEI.
Explicit spatial H.264 packing remains supported.
Temporal pairing, multiview decoding, detection and HDR upgrades are not implemented here.
The existing ordinary decoder, bounded work and cancellation remain authoritative.

The synthetic witness example generates CC0 frame-addressed marked movies and a genuinely flat control; their generated bytes are not bundled assets.
This topic requires the shared craft-media grid owner, built from the named craft-libs revision; it has no craft-stereo-window dependency.

Raw encoded-picture MP4 pasp or H.264 VUI aspect is interpreted once at this boundary.
Compacted rows halve it; compacted columns and checkerboard samples double it without resizing.
An aspect already describing a compacted eye must not be corrected again.
